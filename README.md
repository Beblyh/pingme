# ⏰ PingMe

Локальная веб-напоминалка с таймером, звуковым сигналом (Web Audio API) и системными уведомлениями браузера.

## Возможности
- Создание напоминаний с датой и временем и валидацией ввода.
- Автоматическая сортировка по времени срабатывания и счётчик активных задач.
- Звуковой сигнал и браузерные уведомления (`Notification API`) при наступлении времени.
- Локальное сохранение списка в `localStorage`.

## Установка
Сторонние зависимости не требуются. Нужен любой современный браузер (для запуска приложения) и Python 3.12+ (для запуска автотестов).
